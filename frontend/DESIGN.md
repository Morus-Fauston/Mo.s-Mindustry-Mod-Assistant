# MoMA Web 工作台设计

## 主题
沿用已确认的 R2 工作台：浅色、紧凑三栏、马卡龙类型语义；为长期编辑服务。

## 配色
画布 #fff、侧栏 #f5f6f7、边界 #e3e6ea、正文 #2b2e33；铜橙 #c4702a 作为选中锚点。
数值蓝 #a6d3f2、布尔绿 #a8dcad、字符串杏 #f6d396、数组青 #97dbe6。
所有颜色来自 tokens.css，深色使用同一语义令牌。

## 字体
界面沿用 MiSans / Microsoft YaHei UI，树使用 Segoe UI / Microsoft YaHei UI，数值使用 Consolas。
不依赖下载字体；常规正文13px，树行24px，不给中文加负字距。

## 组件
只用 CSS Modules 与共享CSS变量。按钮3px圆角，细边界，无装饰阴影。
表单复选框20px、勾14px，布尔饰条22px。类型着色、错误和焦点共用语义状态。

## 布局
左文件树、中间编辑、右预览/图层；默认218px与370px侧栏。顶部菜单/工具，底部状态栏。
信息和操作在工作台内，不放营销大标题或无用途活动栏。

## 层次
背景明度与细分隔线形成区域层次；只有浮层需要额外抬升。树选中保留最左3px品牌条。

## 保留与避免
保留用户认可的饰条，优先级高于通用设计技能的色条禁令。不使用emoji、重复默认标签、渐变或玻璃效果。

## 适配
验证1280×800、1440×900、1600×1000及Windows四档DPI。窄栏省略英文附注，中文和完整提示可读。

## 后续组件指导
复用令牌与已有工作台容器，不重新发明主题。编辑状态立即反馈，不对高频键盘动作加动画。
屏幕截图只能证明对应运行环境；真实WebView2与发布包分别留证。
